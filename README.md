# Joseph Cutz Barber

A responsive, high-end static website preview for Joseph Cutz Barber in Nairobi, Kenya.

## Preview

Open `index.html` directly, or publish the repository with any static hosting provider. No build step is required. The page uses the included photographs and studio film stored beside `index.html`.

The opening film starts its soundtrack when a visitor enters the studio, then continues quietly as they explore the page. Browsers require this first user gesture before audio can play.

## Notes

- Menu prices are indicative and should be confirmed with the studio.
- The booking interaction is a front-end preview; it does not send requests to the studio.
- The exact studio address can be added when available.
